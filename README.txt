ARITEL website
==============
Pages: index.html, first-product.html, second-product.html, third-product.html, contact-us.html, privacy-policy.html
Folders: css/ (styles.css), js/, images/

js/script.js        cart number in the navbar, phone menu button, home page product slider
js/products.js      name, price and image of the 3 shirts
js/product-page.js  color, size, quantity, Add to Cart, Order Now (email)
js/contact-us.js    contact form (email) and FAQ
js/privacy.js       "View more.." / "View less.." on the privacy cards

Open index.html in a browser to see the site. To change a price, edit js/products.js
and the price shown in the product page's HTML.
Emails: contact form -> js/contact-us.js, Order Now -> js/product-page.js

Images: some small images (icons, header strip, review photos, privacy icons)
are stand-ins. Replace them with your own files using the same file names.
